soffio 5.0.0, since v4.0.0: the first soffio whose core is fixed.
Soffio is cut to the bone: its markup, its links, its files, and
nothing of what a site is about, as Lua's core is to its host. What a
site wants more is a program of its own, which soffio.Main makes:
soffio with the functions and the checks it adds. The same flags make
the same site, every package is tested to the last statement.
soffio: The module is github.com/jcostd/soffio/v5.
  A path go can fetch, with its major version, as Go wants: a site's
  own program requires it. What it exports is the contract: a site
  extends soffio with functions, a check, templates and programs of
  its own on package soffio, and soffio changes to fix what is wrong,
  not to do more.
soffio: One package, soffio: the language and the command, Main.
  cmd/soffio is soffio.Main(nil, nil); Main(funcs, check) extends it.
  A site's program adds functions for its templates and a check of its
  texts, whose errors come after soffio's, all at once, and has
  soffio's flags, checks and output: a function of soffio's can't be
  taken. Messages are named as the program is run.
soffio: The templates' functions are doc, size and today.
  What only soffio knows: the page of an ID, an image's size, the day
  of the build. sortBy, where, under, reverse, past and rfc822 are
  gone: a site's lists are its own, and its program's functions.
soffio: Languages are gone: -langs, .Lang, .Alternates.
  A language is a word of the site's, as the first directory of its
  IDs; its program says it. .Permalink is gone too: it is
  .BaseURL/.ID.html.
soffio: The header is Meta, all of it, title too: .Title is gone.
  title, layout and visibility, the keys soffio reads, are in Meta as
  any other, and are words, never links or files: .Meta.title, and a
  site's function sorts by it as by any key.
soffio: A header is words, but for title, layout and visibility.
  No key has a type soffio does not need: date, updated, when, until
  and *_date are not checked as dates, image and *_image not as images,
  and id is a key as any other. Two values mean something whatever
  their key: -> target, a link, and a value under /static/, a file,
  checked as an image is.
soffio: A site file has .ID, its name without its extension: 404.
  What a template makes has an ID, where it goes, a page's or not.
soffio: A Document's Lines and HeaderLinks are fields.
  A site's program says file:line of its own rules, as soffio does.
soffio: -baseurl is .BaseURL, empty if not given.
  No default that depends on another flag, no refusal of a public
  site without it: what is asked for is what is made. An address made
  of an empty .BaseURL starts at the root.
soffio: -v is gone: go version -m soffio says which it is.
soffio: Soffio makes HTML pages, a text each, and nothing else.
  No site files: index.html, 404.html, robots.txt, sitemap.xml, rss.xml
  and manifest.json are gone, and .XMLHeader with them. A home and a
  404 page are texts, index.soffio and 404.soffio; a sitemap and a
  robots.txt are made of the pages by what serves them. The templates
  are the .html files of -t, as html/template writes HTML; -baseurl
  needs no longer hold only what it would not escape.
soffio: The built-in template is layout.html, with no word of its own.
  A page leads to the home by its title; no date, no footer. The text
  is an <article> in <main>, the home's list of pages a <nav>.
soffio: href, for the templates: a target's address from a page.
  Relative, written as in a text and made as the texts' are, so a
  template's addresses work under any base, and the built-in site from
  the disk.
README: What soffio makes of the markup, in THE HTML; EXAMPLES, a
  site's program whole, the sitemap made of the pages; SEE ALSO; what
  it can't do, in LIMITS. go doc soffio has examples, run as tests.
soffio: A heading skips no level, and a section holds those below it.
  The first section is ==, each next at most one level below the one
  before: the outline of a page is in its <section>s, not only in its
  headings.
soffio: .Backlinks is gone.
  The pages that link to a page are Links read the other way: a site's
  function, not every site's.
soffio: Render writes no policy and no word.
  A link is <a href>: no target, no rel, as the reader decides where it
  opens. A note's way back is role=doc-backlink, with no aria-label in
  English on a page in any language; its item is a plain li, as
  DPUB-ARIA 1.1 deprecates doc-endnote.
soffio: soffio's errors and the site's check's come at once.
  All of them, soffio's first, as one build; the check reads the texts
  and changes none.
soffio: CheckID and CheckDoc are soffio's own: no one else calls them.
soffio: An image's size is image.Config, the standard library's.
  .Width and .Height, as before.
soffio: A WebP has its size too.
  Read from its first 30 bytes, lossy, lossless or extended, as the
  standard library has no WebP and soffio takes no module for it: 40
  lines in place of a dependency. jpeg, png and gif as before.
preview: Gone from soffio.
  A server is not soffio's job: any static one serves a site, and the
  Fucina's writers have theirs in fucina-engine.
soffio: Links reads the targets of check's walk: one walk of a text.
soffio: An image has its width and height.
  Read from its file in -s (jpeg, png, gif), in the texts as size gives
  them to templates: the browser keeps an image's place before it
  comes, and the page doesn't jump.
soffio: A header key a page doesn't have is "" to the templates.
  As one it has empty, as Go's zero value: .Meta.by is a string to a
  function either way.

soffio 4.0.0, since v3.1.1. Pages know the pages that link to them,
and a header can hold a link. A page has one name, its file's.
soffio: The id header is refused: a text's ID is its file's name.
  Two names for one page could only part; a translation is linked by
  its path, which the file gives.
soffio: .Children is gone: under .Docs .ID is the same, and one way.
soffio: index.html is a site file, made if its template is there.
  The root of a site with languages, whose homes are <lang>/index:
  where / leads, for a browser and for a preview.
soffio: A header value -> target is a link to a page.
  Written and checked as a link in the body: from the text's
  directory, to a page that is there and public. The templates get the
  ID of the page, so .Docs gives its title: artist: -> ../persone/arp.
  A section, a file or an address out of the site is refused: a header
  link names a page. layout and the dates never hold one.
soffio: A page gets .Backlinks, .Docs and .ID.
  .Backlinks are the pages that link to it, from their header or their
  body, by ID: a link is written once and read from both ends. .Docs is
  every page by ID, as the site files had.
soffio: where, under and reverse, for templates; sortBy takes .Docs.
  where keeps the pages whose header key has a value: where .Backlinks
  "layout" "opera". under keeps the pages under an ID, as .Children:
  under .Docs .Lang is a language. reverse turns a list round, lowest
  first after sortBy.
soffio: The built-in layout lists the pages that link to a page.
soffio: A date can be as precise as what is known of it.
  YYYY-MM-DD, YYYY-MM or YYYY, in every date key: 'when: 1954' is a
  year, not its first of January. They sort as text in time's order.
  when and until join date, updated and *_date: the time of what a
  text is about, and its end.
soffio: A page in a list has .Lang; doc gives the page of an ID.
  A template given a page, as a partial is, knows its language and
  finds the pages its header names: doc .Meta.by, nil if none.
soffio: -today day gives the templates today.
  Their only clock, an input as -baseurl is: without it today is
  empty, and the same flags make the same site.
soffio: past date tells a template whether a date has passed.
  As of -today, as precise as the date is written: 2027-03 lasts all
  March. Without -today nothing has.

soffio 3.0.0, since v2.1.0. Fewer flags, no warnings, many more
checks in 7% less code, three times faster.
soffio: The command line is smaller.  (* Changes the interface. *)
  soffio [-a] [-n] [-baseurl url] [-langs l,...] [-o dir] [-s dir]
  [-t dir] dir. -a takes the private texts too, for -vis all; without
  it they are left out, as -vis public did. -n checks everything,
  templates included, and writes nothing, for the six -html=false
  -rss=false ... flags. Gone: -vis, -html, -rss, -sitemap, -robots,
  -errpage, -manifest, -version (-v stays). -s and -t have no default:
  no static dir, the built-in templates. Extra arguments are refused.
soffio: Templates come from -t or are the built-in ones, never a mix.
  A site has what is in its directory: one without 404.html gets no
  404 page. rss.xml, sitemap.xml, robots.txt, 404.html and manifest.json
  are made when their template is there.
soffio: No warnings: what was one is an error.
  A missing image, a note never referenced, a link to a missing file
  under /static/ (now checked, not refused as a missing page), a layout
  that is not there (it fell back to layout.html in silence).
soffio: Messages are file:line: message, with no timestamps.
  They named the document ID, and log put a date in front of each.
soffio: More is refused, with a reason.
  A visibility other than public or private; a duplicate header key,
  section ID or note ID; an empty ID, list item or image path; an
  image not under /static/ (it was checked in one place and served
  from another); an ID from a file or directory name that breaks the
  ID rules; a text under static/; a -langs language that can't be a
  directory; an -s or -t that is not a directory.
soffio: Pipe mode checks what a text can check alone.
  Its notes, and its links to its own sections: a ref to a missing
  note gave a dangling link and exit 0.
soffio: A note referenced only from another note is an endnote too.
  Its ref pointed nowhere.
soffio: Images are addressed relative to the page, as links are.
  /static/a.png from it/x is ../static/a.png: the site works under any
  base, even opened from the disk.
soffio: rfc822 for templates; the built-in rss.xml uses it.
  RSS wants Wed, 19 Aug 2026 00:00:00 +0000, not 2026-08-19.
soffio: A link to a directory in -s is refused, as it may loop.
  It came out as an empty directory.
go.mod: go 1.26, not 1.26.2: any Go 1.26 builds soffio, as the README
  says. go1.26.0 builds it and passes every test.
release.sh: Refuses a tree that is not clean, or not tagged v$VERSION.
release.sh: The archives hold templates/, the built-in templates as
  files, to start a -t of one's own from.
soffio: -s and <o>/static can't overlap, however the paths are spelled.
  -s public/static -o public copied every file onto itself, and that
  emptied it: a.png came out 0 bytes.
soffio: A note referred to only by itself, or by notes the text never
  reaches, is "never referenced". Render left it out, and the check
  passed it: text was lost with exit 0.
soffio: A link inside a link, or a note ref in a link label, is refused.
  It made an <a> inside an <a>.
soffio: An invalid address, as nope%zz, is refused. It went unchecked.
soffio: Absolute targets are cleaned, as relative ones were.
  /it/x/../about is it/about, and /static/../../etc/passwd no file.
soffio: A byte order mark at the start of a text is ignored, as Go does.
  Notepad may write one: the id: line after it was not read, and the
  page got the file's name.
soffio: Invalid UTF-8 is refused, with its line.
soffio: Header keys are letters, digits and _.
  A section line in the header, == s | Title: sub, was a key.
soffio: A list item starts with "- ". "-5 gradi" was a list.
soffio: Hidden files and directories in the texts and in -s are skipped.
soffio: A link to a hidden file under -s is refused.
  It passed the check, but the file is never copied: a broken link.
soffio: -n checks the copy of -s too, and writes nothing.
  A link to a directory in -s, or -o inside -s, gave exit 0 with -n
  and exit 1 in the build. A broken link in -s says where it is.
soffio: The public site needs -baseurl.  (* Changes the interface. *)
  It was http://localhost:8080 if not given, so a public build that
  forgot it pointed its feeds and canonical links there, with exit 0.
  With -a or -n it still is, for the preview.
soffio: Notes have no heading but notes_title.  (* Changes the look. *)
  It was "Notes", in English on an Italian page.
soffio: Note anchors are fn:x, fnref:x:1 and footnotes:<id>.
  A section fn-x and a note x had the same id; no section ID holds ':'.
soffio: A line starting with :: is a command, or is refused.
  ::img: /static/a.png | a, a slip for :: img:, was a paragraph.
soffio: soffio file.soffio says it is not a directory, not "stat .".
preview: It builds on the BSDs: one xdg-open, open or start for all.
  The usage is one line; extra arguments are refused, as by soffio.
soffio: -t can't be -o.
  soffio -t site -o site wrote rss.xml and 404.html over their
  templates, with exit 0.
soffio: -s can be given more than once.
  Everything in -s is published; the files only drafts use go in a
  -s of their own that only the preview gets: -a -s static -s drafts.
  A public text pointing at one is a missing file. A path in two -s,
  or twice in letter case only, is refused.
soffio: A page needs a title.
  One without was an empty link, so unseen, in every list of pages.
soffio: In pipe mode -n only checks; a flag about the site is refused.
  soffio -o x < t.soffio ignored -o.
soffio: .Lang for templates: the language of the page, from its ID.
  A text needs no lang: header for <html lang>.
soffio: The built-in templates need only a title.  (* Changes the look. *)
  date and updated are shown if a text has them; description, author,
  image, json-ld and the manifest are gone. They show .Lang, a language
  switch, children by date, rfc822. sitemap.xml no longer lists /,
  which may not be there. A -t with manifest.json still makes it.
  The ._ files macOS leaves on other disks were parsed as texts.
soffio: A link to a directory among the texts is refused, as in -s.
soffio: A text named like a site file, as 404.soffio, is refused.
  The 404.html template overwrote it.
soffio: static/ is refused as an ID in any case: Static/ is one with it
  on Windows and macOS.
soffio: -baseurl must be http(s)://host[/path], and -langs can't repeat
  a language. https://x.org/c++ came out c&#43;&#43; in robots.txt and
  manifest.json.
soffio: Inline markup is parsed in linear time.
  A 150 KB line of *a *a ... took 12 s, nested links 2 s; a few ms now.
  Found by fuzzing, which is now part of the tests.
soffio: IDs are escaped in HTML attributes, as everything else is.
preview: A directory that is not there is refused, and no timestamps.
soffio: Fixed links to a page whose ID has a dot in it.
  (see -> v1.2) linked to v1.2 instead of v1.2.html, and the check
  passed it. Only a target under static/ is a file; anything else is a
  page.
soffio: Fixed hreflang alternates.
  On Windows there were none: IDs were looked up with backslashes. And
  blog/x got an alternate in en/x, though blog is no language: the
  first part of an ID is a language only if -langs says so.
soffio: .Children comes sorted by ID.
  It came in map order, so a layout ranging over it, like Fucina's
  galleria, shuffled on every build.
soffio: A -baseurl ending in '/' is refused.
  It gave https://x.org//page.html everywhere.
soffio: Markers only at the edges of a word.
  snake_case_name became snake<em>case</em>name; now a * or _ opens only
  at the start of a word and closes only at its end. (*x) is a note
  only if x is a valid note ID, so (*bold*) is bold in parentheses, no
  longer a broken note that failed the build.
soffio: Errors about a block name the line where it starts.
  "content outside any section" named the line after the block.
soffio: Files are read in lexical order, one after the other.
  Errors and duplicate IDs come out in the same order on every run;
  the file reported as duplicate is the later one.
soffio: Every output file is written in one call.
  html/template writes in small pieces, one syscall each: that was 59%
  of the time. A 4816-text site builds in 1.2 s instead of 3.8. A page
  that fails leaves no half-written file, and a failed close is an
  error.
soffio: rss.xml has the same XML declaration as sitemap.xml.
  <?xml version="1.0" encoding="UTF-8"?>, without the space before ?>.
source: ast, parser, corpus and renderer are one package, soffio.
  Nothing outside imported them, and their borders only made links be
  resolved twice. Now one function says where a link points, for the
  check and for the HTML alike. The parser cuts the body into blocks,
  then each block's first line says what it is: no state machine.
  Inline markup is scanned by byte. Code: 1397 lines down to 1074,
  then 1148 with all the checks and flags above.
  Still the standard library only.
