#+TITLE: Soffio
#+AUTHOR: Jacopo Costantini
#+OPTIONS: toc:nil num:nil

Soffio is a static site generator. Text in, HTML out. It reads =.soffio= files,
validates internal links across the corpus, and writes a static site preserving
the input directory structure. Zero external dependencies.

* Markup

#+BEGIN_SRC text
id: about
title: About This Project

== intro | Introduction

A paragraph with *bold* and _italic_ text.
A single newline continues the same block.

- First list item
- Second item with a (link -> other-doc)
- Third item with a footnote(*n1)

== gallery | Gallery

:: img: static/img/photo.jpg | A caption with _italic_.

:: note: n1 | Footnote text rendered at end of document.
#+END_SRC

* Syntax

| Construct     | Syntax                           |
|---------------+----------------------------------|
| Section       | ~===id ｜ Title=~                |
| Bold          | ~*text*~                         |
| Italic        | ~_text_~                         |
| Internal link | ~(Label -> doc-id)~              |
| External link | ~(Label -> https://example.com)~ |
| Footnote ref  | ~(*note-id)~                     |
| Image         | ~:: img: path ｜ caption~        |
| Footnote def  | ~:: note: id ｜ text~            |
| List item     | ~- text~                         |

A blank line ends a block. A =layout= key in the frontmatter selects an
alternate template.

* Build

#+BEGIN_SRC bash
make        # build soffio and preview binaries
make public # generate the site
make serve  # generate and start the preview server
make test   # run tests with race detector
make clean  # remove binaries and generated output
#+END_SRC

Requires Go 1.26+.

* Usage

#+BEGIN_SRC bash
./soffio [-i content] [-o public] [-t templates]
./preview [-d public] [-p 8080]
#+END_SRC

=soffio= reads =.soffio= files from =-i=, writes HTML to =-o=, and loads layout
templates from =-t=. If =-t= directory is absent, the embedded fallback template
is used. Files in =<input>/static/= are mirrored verbatim to =<output>/static/=.

=preview= serves =-d= on =:-p= and opens the system browser.

* Structure

#+BEGIN_EXAMPLE
<input>/              .soffio source files
<input>/static/       assets mirrored verbatim to <output>/static/
<templates>/          layout overrides (optional)
<output>/             generated HTML (discardable)
cmd/soffio/           compiler
cmd/preview/          local preview server
#+END_EXAMPLE

* Routing

The filesystem scopes the output directory. The frontmatter =id= field names the
output file. =<input>/it/about.soffio= with =id: my-id= becomes
=<output>/it/my-id.html=. If =id= is absent, the filename is used as fallback.
Internal links use the composite path: =(Label -> it/my-id)=.
