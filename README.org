#+TITLE: Soffio
#+AUTHOR: Jacopo Costantini
#+OPTIONS: toc:nil num:nil

Soffio is a static site generator. Text in, HTML out. It reads =.soffio= files,
validates internal links across the corpus, and writes a static site preserving
the input directory structure. Zero external dependencies.

* Markup

#+BEGIN_SRC text
id: about
title: About This Project

== intro | Introduction

A paragraph with *bold* and _italic_ text.
A single newline continues the same block.

- First list item
- Second item with a (link -> other-doc)
- Third item with a footnote(*n1)

== gallery | Gallery

:: img: static/img/photo.jpg | A caption with _italic_.

:: note: n1 | Footnote text rendered at end of document.
#+END_SRC

* Syntax

| Construct     | Syntax                           |
|---------------+----------------------------------|
| Section       | ~== id ｜ Title~                 |
| Bold          | ~*text*~                         |
| Italic        | ~_text_~                         |
| Internal link | ~(Label -> doc-id)~              |
| External link | ~(Label -> https://example.com)~ |
| Footnote ref  | ~(*note-id)~                     |
| Image         | ~:: img: path ｜ caption~        |
| Footnote def  | ~:: note: id ｜ text~            |
| List item     | ~- text~                         |

A blank line ends a block. A =layout= key in the frontmatter selects an
alternate template.

* Build

#+BEGIN_SRC bash
  make         # build soffio and preview binaries
  make soffio  # build only soffio binary
  make preview # build only preview binary
  make clean   # remove binaries and generated output
#+END_SRC

Requires Go 1.26+.

* Usage

#+BEGIN_SRC bash
  # Site generator mode
  soffio [flags] <src_sir>

  # Pipe mode (stdin -> stdout)
  soffio < input.soffio

  # Preview server
  preview [flags] [dir]
#+END_SRC

** Flags for =soffio=

- =-o= :: Output directory (default: =public=)
- =-t= :: Local templates directory (default: =templates=)
- =-s= :: Static assets directory (default: =static=)
- =-vis= :: Visibility filter: =public=, =private=, =all= (default: =public=)
- =-html= :: Generate HTML pages and index (default: =true=)
- =-rss= :: Generate RSS feed (default: =true=)
- =-sitemap= :: Generate XML sitemap (default: =true=)
- =-v=, =-version= :: Print version and exit

** Flags for =preview=

- =-d= :: Directory to serve (default: =public=, or positional arg)
- =-p= :: Port to listen on (default: =8080=)

* Structure

#+BEGIN_EXAMPLE
<src_dir>/             .soffio source files
<src_dir>/static/      assets mirrored verbatim to <out>/static/
templates/             custom template overrides (optional)
cmd/soffio/            site generator CLI
cmd/preview/           local preview web server
VERSION                plain-text version identifier
release.sh             cross-compilation script
dist/                  compressed release packages
#+END_EXAMPLE

* Routing

The filesystem scopes the output directory. The frontmatter =id= field names the
output file. =<input>/it/about.soffio= with =id: my-id= becomes
=<output>/it/my-id.html=. If =id= is absent, the filename is used as fallback.
Internal links use the composite path: =(Label -> it/my-id)=.
